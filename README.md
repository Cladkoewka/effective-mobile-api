# Effective Mobile API

API для получения данных о людях (пол, возраст, национальность) с использованием внешних API и сохранением данных в базе данных.

## Описание

Этот проект реализует сервис, который получает по API ФИО, обогащает их с использованием открытых API для определения пола, возраста и национальности, и сохраняет результаты в базе данных PostgreSQL. 

Возможности:

- Получение данных с различными фильтрами и пагинацией
- Удаление записи по идентификатору
- Обновление записи
- Добавление новых людей с обогащением данных
- Генерация Swagger документации для API

## Структура проекта

- **cmd/main.go** - основной файл для запуска приложения
- **internal/api/enrichment** - клиент для взаимодействия с внешними API для обогащения данных
- **internal/config** - загрузка конфигурации и настройка приложения
- **internal/handler** - обработчики HTTP-запросов
- **internal/logger** - настройка логирования
- **internal/repository** - взаимодействие с базой данных
- **internal/service** - бизнес-логика приложения
- **migrations/** - миграции для базы данных

## Установка и настройка

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Cladkoewka/effective-mobile-api.git
   cd effective-mobile-api

2. Создайте файл `.env` в корне проекта с настройками для подключения к базе данных:

   ```env
   PORT=8080

   DB_HOST=localhost
   DB_PORT=5434
   DB_USER=user
   DB_PASSWORD=password
   DB_NAME=effective_mobile_db
   ```

3. Установите зависимости:

   ```bash
   go mod tidy
   ```

4. Запустите миграции (если необходимо):

   Для выполнения миграций используйте флаг `-migrate`:

   ```bash
   go run cmd/main.go -migrate
   ```

5. Запустите сервер:

   ```bash
   go run main.go
   ```

6. API будет доступно по адресу: `http://localhost:8080(или порт который вы указали в .env)`.

## API

### Получить информацию о человеке по ID

* **URL**: `/persons/{id}`
* **Метод**: `GET`
* **Описание**: Получение информации о человеке по его ID.
* **Параметры**:

  * `id` (обязательный) - ID человека.
* **Ответ**:

  * 200 OK: Возвращает объект с информацией о человеке.
  * 400 Bad Request: Неверный параметр ID.
  * 404 Not Found: Человек не найден.
  * 500 Internal Server Error: Внутренняя ошибка сервера.

### Получить всех людей с фильтрацией и пагинацией

* **URL**: `/persons`
* **Метод**: `GET`
* **Описание**: Получение списка людей с возможностью фильтрации, сортировки и пагинации.
* **Параметры**:

  * `name` (необязательный) - имя для фильтрации.
  * `surname` (необязательный) - фамилия для фильтрации.
  * `page` (необязательный) - номер страницы для пагинации (по умолчанию 1).
  * `limit` (необязательный) - количество записей на странице (по умолчанию 10).
* **Ответ**:

  * 200 OK: Список людей.
  * 400 Bad Request: Неверные параметры запроса.
  * 500 Internal Server Error: Внутренняя ошибка сервера.

### Создать нового человека

* **URL**: `/persons`

* **Метод**: `POST`

* **Описание**: Создание нового человека с обогащением данных.

* **Тело запроса**:

  ```json
  {
      "name": "Dmitriy",
      "surname": "Ushakov",
      "patronymic": "Vasilevich"  // необязательно
  }
  ```

* **Ответ**:

  * 201 Created: Успешное создание.
  * 400 Bad Request: Неверный формат данных.
  * 500 Internal Server Error: Внутренняя ошибка сервера.

### Обновить данные о человеке

* **URL**: `/persons/{id}`

* **Метод**: `PUT`

* **Описание**: Обновление данных о человеке по его ID.

* **Параметры**:

  * `id` (обязательный) - ID человека.

* **Тело запроса**:

  ```json
  {
      "name": "Dmitriy",  // необязательно
      "surname": "Ushakov",  // необязательно
      "patronymic": "Vasilevich"  // необязательно
  }
  ```

* **Ответ**:

  * 200 OK: Успешное обновление.
  * 400 Bad Request: Неверный ID или формат данных.
  * 500 Internal Server Error: Внутренняя ошибка сервера.

### Удалить человека

* **URL**: `/persons/{id}`
* **Метод**: `DELETE`
* **Описание**: Удаление человека по его ID.
* **Параметры**:

  * `id` (обязательный) - ID человека.
* **Ответ**:

  * 204 No Content: Успешное удаление.
  * 400 Bad Request: Неверный ID.
  * 500 Internal Server Error: Внутренняя ошибка сервера.

## Контейнеризация с Docker

Для использования Docker, используйте следующий `docker-compose.yml` для настройки контейнера с PostgreSQL:

```yaml
services:
  db:
    image: postgres:latest
    container_name: postgres_db
    environment:
      POSTGRES_DB: ${DB_NAME}
      POSTGRES_USER: ${DB_USER}
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    ports:
      - "${DB_PORT}:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

Запуск:

```bash
docker-compose up
```
